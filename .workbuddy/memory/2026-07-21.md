## 首页用药/症状时间线 icon 加主题色（修复遗漏）
- 现象：首页记录列表里用药(💉)、症状(🤒)的 icon 方块是粉色兜底（--card-pink），与其他类型（feeding/sleep/play 等）的彩色方块不一致。
- 根因：新增 medicine/symptom 类型时只加了数据/路由/分支，漏了主题色系统三件套——`styles.css` 的亮/暗 `--t-*` 变量、`Home.vue` 的 `.tl-{type} { --tt: var(--t-{type}) }` 映射。模板 `.tl-icon` 用 `color-mix(in srgb, var(--tt) var(--icon-tint), var(--card))` 上色，`--tt` 未定义时回退 `--card-pink`。
- 修复：① `styles.css` 亮色块加 `--t-medicine:#e5484d; --t-symptom:#f5a623;`，暗色块加 `--t-medicine:#ff6b6b; --t-symptom:#ffc94d;`（用药=红/警示感，症状=琥珀黄）；② `Home.vue`(L1546后) 加 `.tl-medicine { --tt: var(--t-medicine); }` 与 `.tl-symptom { --tt: var(--t-symptom); }`。模板 `:class="'tl-'+it.type"` 自动套用。
- 前端 dev server(5173) HMR 已热更，刷新即可看到两个类型 icon 上色。源码改动未提交，待用户「提交/发版」指令。
