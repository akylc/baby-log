## 首页用药/症状时间线 icon 加主题色（修复遗漏）
- 现象：首页记录列表里用药(💉)、症状(🤒)的 icon 方块是粉色兜底（--card-pink），与其他类型（feeding/sleep/play 等）的彩色方块不一致。
- 根因：新增 medicine/symptom 类型时只加了数据/路由/分支，漏了主题色系统三件套——`styles.css` 的亮/暗 `--t-*` 变量、`Home.vue` 的 `.tl-{type} { --tt: var(--t-{type}) }` 映射。模板 `.tl-icon` 用 `color-mix(in srgb, var(--tt) var(--icon-tint), var(--card))` 上色，`--tt` 未定义时回退 `--card-pink`。
- 修复：① `styles.css` 亮色块加 `--t-medicine:#e5484d; --t-symptom:#f5a623;`，暗色块加 `--t-medicine:#ff6b6b; --t-symptom:#ffc94d;`（用药=红/警示感，症状=琥珀黄）；② `Home.vue`(L1546后) 加 `.tl-medicine { --tt: var(--t-medicine); }` 与 `.tl-symptom { --tt: var(--t-symptom); }`。模板 `:class="'tl-'+it.type"` 自动套用。
- 前端 dev server(5173) HMR 已热更，刷新即可看到两个类型 icon 上色。源码改动未提交，待用户「提交/发版」指令。

## 首页类型筛选改为单条件筛选（用户需求）
- 需求：首页记录类型筛选从「多选」改为「单条件筛选，一次性只能选一个」；原「全选」按钮改为「所有」，点击清空筛选类型（=展示全部）。
- 改动（`frontend/src/views/Home.vue`）：
  - 模型：`typeFilter` 仅允许 0（所有）或 1 个类型。`loadFilter()` 默认返回 `[]`（所有），并对旧版多选 localStorage 数据做归一化（length>1 或非法一律回退 `[]`，避免残留多选）。
  - `toggleType(v)`：改为单条件切换——`typeFilter = typeFilter[0]===v ? [] : [v]`（点类型仅选中它；再点同类型取消回所有）。
  - 「全选」按钮 → 改名「所有」、`@click="clearFilter"`，`clearFilter()` 设 `typeFilter=[]`（展示全部）。移除原「取消选中」按钮（与「所有」语义重合）。
  - `isFilterActive` 语义反转：`length < ALL_TYPES.length` → `length > 0`（选中具体类型才算筛选中）。
  - `rebuild()` 贯穿「空=所有」：新增 `noFilter = set.size===0`；feedings/sleeps/diapers/plays/cares/symptoms/medicines 在 `noFilter` 时直接展示全部（否则按 `set.has` 单类型过滤）；昨日衔接点 `prevBumps` 各 `if` 改为 `noFilter || set.has(...)`，确保「所有」状态也显示跨日衔接。
- 验证：`pnpm --filter frontend build` 通过（2901 模块，无类型错误）；前端 dev server(5173) 在线、HMR 已热更，刷新即可。源码改动未提交，待用户「提交/发版」指令。
